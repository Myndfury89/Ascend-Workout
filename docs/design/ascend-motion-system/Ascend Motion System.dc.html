MOTION SPEC — REFERENCE
Motion verbs
Assemble — geometry, panels, sigils form from fragments and traced lines.
Charge — energy gathers before an important progression event.
Lock — values and results snap into a final precise state.
Ascend — rank geometry and identity elements permanently gain complexity.
Timing tokens (validated defaults)
ASSEMBLE850mscubic-bezier(0.16,1,0.3,1)
CHARGE1100mscubic-bezier(0.65,0,0.35,1)
LOCK380mscubic-bezier(0.34,1.56,0.64,1)
ASCEND2200mscubic-bezier(0.22,1,0.36,1)
REDUCED140mslinear cross-fade
Charge is the least validated token — re-check feel at real particle counts / on-device frame rate.
Tiers
Everyday 200–700ms — status, nav, forms, quest progress. Lock is the reference.
Reward 700–1500ms — quest complete, PR, attribute up, XP. Charge is the reference. Reduced motion still needs a non-kinetic cue.
Ascension 1500–3000ms, rare — class pick, skill unlock, level milestone, rank promotion. Assemble + Ascend are the reference.
Event priority
1. Ascension interrupts Reward and Everyday.
2. Reward interrupts Everyday, never Ascension.
3. Concurrent Reward events queue and settle sequentially into the sigil.
4. Everyday motion never blocks input; Ascension may hold input briefly for readability.
Reduced motion
All four verbs collapse to a single 140ms linear cross-fade. No rotation, fog, fragment assembly, or large scale. Final values render immediately.
Reward-tier events still emit a brief non-kinetic cue — a flat color pulse here — so a personal record never reads as silence.
Class sigil language (production: Berserker / Monk / Magician)
Berserker — 4-point spike-star core anchor, single bold star-polygon middle layer, heavier stroke weight, slowest/heaviest drift. No square forms.
Monk — hexagon core anchor, balanced two-triangle hexagram middle layer, even stroke weight, moderate measured drift.
Magician — circular core anchor, four overlapping flowing rings as the middle layer, thinnest stroke, fastest and lightest drift (reversed direction).
Future direction (not yet fully animated): Assassin — lean asymmetric blade-facets, quick sharp micro-pulses. Fighter — compact mixed polygon/ring core, rhythmic alternating pulses. Ranger — open long arc sweeps, sustained outward-pathing drift. Guardian — layered concentric shield-rings, slow reinforcing pulses.
Performance posture
Everyday / Reward: real-time procedural motion on alpha, translation, scale, path-trim — cheap per-frame cost.
Ascension: glow / bloom / fragment assembly are pre-authored (AnimatedVectorDrawable or composited sprite sequence), not recomputed live. One glow source per screen; secondary elements react via color + scale only.
